# ATURAN KETAT PACKAGE MANAGER: WAJIB MENGGUNAKAN `pnpm`

1. **STANDAR PACKAGE MANAGER**:
   - Seluruh agen AI dan developer WAJIB menggunakan `pnpm` untuk semua operasi frontend dan manajemen dependensi Node.js.
   - Contoh perintah wajib:
     - `pnpm install` (bukan `npm install` atau `yarn install`)
     - `pnpm build` atau `pnpm run build` (bukan `npm run build`)
     - `pnpm dev` atau `pnpm run dev`
     - `pnpm add <package>` (bukan `npm i <package>`)
     - `pnpm dlx` (bukan `npx`)

2. **DILARANG MENGGUNAKAN `npm` ATAU `yarn`** kecuali jika ada instruksi eksplisit dari USER.
